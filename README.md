# ブドウ相場ボード

東京都中央卸売市場（豊洲・大田・豊島・淀橋・板橋・世田谷・北足立・多摩NT・葛西の9市場）の
日報「販売結果（青果）」から、**ぶどうの品種別・産地別・市場別の卸値**を毎日集めて
ダッシュボードを公開します。GitHub Actions が毎朝10時（JST）に自動実行するので、
PC を起動しておく必要はありません。

- 出典: <https://www.shijou-nippo.metro.tokyo.lg.jp/>（速報値）
- 品種: 日報に載るものをすべて（シャインマスカット・巨峰・ピオーネ・デラウェア・アレキサンドリアほか、
  季節ごとに入れ替わる品種も自動で拾います）
- 価格: 日報の高値・中値・安値を、掲載単位（1ケースあたりkg）で割って **円/kg** に換算

## セットアップ（初回だけ、5分）

1. GitHub で新しいリポジトリを作る。名前は何でもよい（例: `budou-shijou`）。
   **Public** を推奨（Private だと GitHub Pages が有料プラン限定になります）。
2. このフォルダの中身をまるごとアップロードする。
   リポジトリの「Add file」→「Upload files」に、フォルダごとドラッグ＆ドロップでOK。
   `.github` フォルダも忘れずに（隠しフォルダなので Finder/エクスプローラの設定で表示させてください）。
   うまく上がらなければ「Add file」→「Create new file」でファイル名に
   `.github/workflows/collect.yml` と打ち込み、同名ファイルの中身を貼り付けても同じです。
3. リポジトリの **Settings → Pages** を開き、**Source** を「GitHub Actions」にする。
4. **Actions** タブ →「ブドウ相場の収集」→「Run workflow」で手動実行し、緑チェックになるのを確認する。
5. 完了。以後は毎朝10時（JST）に自動で動き、
   `https://<ユーザー名>.github.io/<リポジトリ名>/` が常に最新になります。

## ファイル構成

```
collect.py                  収集 → 正規化 → サイト生成（標準ライブラリのみ）
template.html               ダッシュボードの見た目（__DATA__ にデータが入る）
.github/workflows/collect.yml  毎日10時(JST)の自動実行
raw_history.csv             日報から取った生データ（追記・重複排除ずみ・2026-07-02〜）
budou_prices.csv            円/kg に換算した正規化データ（Excelで開けます）
site/index.html             公開されるダッシュボード（自動生成・直接編集しない）
site/data.json              グラフ用データ（自動生成）
```

## 仕組み

`collect.py` は各市場の日報 CSV
（`/SN/{YYYYMM}/{YYYYMMDD}/Sei/Sei_K{1..9}.csv`、文字コードは CP932）を直接読み、
`ぶどう` の行だけを取り出します。**直近12日分を毎回さかのぼる**ので、
数日止まっていても自動で追いつきます。
`(日付, 市場, 販売方法, 品種, 産地, 単位)` で重複排除しているため、
同じ日を何度取り込んでも二重になりません。

## 品種を網羅する

日報の品種欄は季節で入れ替わります（例：アレキサンドリアは7月まで、ピオーネは8月から）。
`collect.py` は品種を決め打ちせず**出てきたものをすべて**拾い、ダッシュボードも
データにある品種を自動で並べます。過去にさかのぼるほど顔ぶれが揃うので、
初回は Actions の Run workflow で `さかのぼる日数` に `400` などを指定してください。

実行ログの末尾に「品種の顔ぶれ」が出ます。出典は品種名を**7文字で切る**ため、
`シャインマスカ` のような表記が現れます。ログで `← 要確認` が付いた名前を
`collect.py` の `VARIETY_FIX` に足せば、以後は正式名で表示されます。

## 手を入れるとき

- **さかのぼる日数を変える**: ワークフローに `env: DAYS_BACK: "30"` を足す。
- **実行時刻を変える**: `collect.yml` の cron（UTC）を変更。JST = UTC + 9時間。
- **品種名が切れている**: 出典側の仕様で「シャインマスカ」等と省略されることがあります。
  新しい切れ方が出たら `collect.py` の `VARIETY_FIX` に追加してください。
- **見た目を変える**: `template.html` を編集すれば次回実行から反映されます。

## 注意

日報は**速報値**で、確定値と異なる場合があります。休市日（日曜・祝日・水曜休市など）は
データがありません — ログの「休市・未掲載」件数が多くても異常ではありません。
